## Introduction

JARVIS AI Assistant is a web-based voice assistant designed to replicate Tony Stark's artificial intelligence assistant. It provides interactive voice response, AI-powered conversational Q&A, instant web browsing, music playing capabilities, and quick system tools.

---

## Features

- 🎙️ **Voice Recognition**: Hindi & Hinglish voice input handling.
- 🗣️ **Voice Output**: Natural audio responses via SpeechSynthesis.
- 🧠 **AI Chat**: Powered by Google Gemini (`gemini-3.8-flash`) with smart memory management.
- 🌐 **Web Browsing**: Launch instant Google searches directly through voice commands.
- 🎵 **Music Playback**: Search and play songs on YouTube using voice commands.
- 🕒 **Time & Date**: Real-time voice response for current time and date.
- 📝 **Quick Notes**: Add and store notes in local browser memory.

## Getting Started

### Prerequisites

- Google Chrome Browser (on Mobile/Tablet/PC)
- Google Gemini API Key (Free from Google AI Studio)

### Setup

1. Open the hosted web app: `https://darshiii360.github.io/Jarvis-/`
2. Click on **Settings** in the top right corner.
3. Paste your **Google Gemini API Key**.
4. Click **Save**.

---

## Usage

Tap the **Mic** button or type your query in the input box to start interacting.

### Example Voice Commands

- **AI Q&A**: *"Quantum computing kya hota hai?"*
- **Web Search**: *"Search latest tech news"*
- **Music**: *"Play song Arijit Singh new song"*
- **Time/Date**: *"Abhi kitne baje hain?"*
- **Notes**: *"Note likho meeting at 5 PM"*
